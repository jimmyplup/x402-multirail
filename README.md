# x402-multirail

Multi-chain [x402](https://www.x402.org) seller rails for Express. One paid endpoint can be bought
on **Base**, **Celo** (USDC, USDT, USA₮) and **Arc** at the same time: the 402 lists every rail, and a
payment is verified, settled and confirmed on the rail the buyer chose — that chain's facilitator,
that chain's RPC, that token, that payTo — and nothing else.

Extracted from the billing code of [Synap](https://pool.linkrra.com/ai), Linkrra's OpenAI-compatible
inference API, where it backs pay-per-call inference, TTS and credit top-ups. Every file here is a
verbatim copy of the production module and its tests (generated by `ops/export-x402-multirail.sh`).

## Why it exists

`extra.name` / `extra.version` in an x402 `exact` requirement is the token's **EIP-712 domain** — the
thing the buyer signs over. It differs per chain *and* per token: Base USDC is `"USD Coin"`, but Base
Sepolia, Celo and Arc USDC are `"USDC"`; Celo USDT is `"Tether USD"` v1 and USA₮ is
`"Tether America USD"` v1, and neither has a `version()` method. A hard-coded domain is right on at
most one chain, and when it is wrong nothing errors — every spec-following client just signs a digest
the token rejects. We shipped exactly that bug on Base for seven weeks before a third-party verifier
caught it. This package makes the domain a per-chain table, and proves the table against the chain.

## Rails

| Network | CAIP-2 | Token | EIP-712 domain | Facilitator (default) | Auth |
|---|---|---|---|---|---|
| Base | eip155:8453 | USDC `0x8335…2913` | USD Coin / 2 | configurable (CDP, PayAI, Circle) | Bearer / CDP JWT |
| Celo | eip155:42220 | USDC `0xcebA…118C` | USDC / 2 | https://api.x402.celo.org | `X-API-Key` |
| Celo | eip155:42220 | USDT `0x4806…3D5e` | Tether USD / 1 | same | same |
| Celo | eip155:42220 | USA₮ `0xD2ab…F771` | Tether America USD / 1 | same | same |
| Arc | eip155:5042 | USDC `0x3600…0000` | USDC / 2 | https://api.circle.com/v1/facilitator/x402 | Circle API key (Bearer) or keyless-trial seller proof |
| Celo Sepolia / Arc testnet / Base Sepolia | — | USDC | as on-chain | as above | as above |

Every domain above reproduces the token's on-chain `DOMAIN_SEPARATOR()` (read over RPC 2026-10-17);
the separators are pinned in `test/test-x402-networks.js`.

## What is guaranteed (each one is a test)

- **Single-rail compatibility** — with no extra rails the 402 is byte-identical to the single-network
  body (`test-x402-rails.js` #1).
- **Settle on the payer's rail only** — the payload's `accepted.network` + `asset` pick the rail; an
  unoffered chain or token is refused with a 402 **before any facilitator call** (#3a–3c).
- **The facilitator is not trusted** — every settlement is re-read from the chain's RPC; only the paid
  token's `Transfer` to our payTo counts. Arc's 18-decimal system `Transfer` log and Celo
  fee-currency logs never add up (#7a, #7b).
- **No double charge on pending** — Circle's `settlement_pending` becomes a 202 "retry the SAME header",
  never a fresh 402 (#6).
- **Facilitator auth on the wire** — Celo gets `X-API-Key` and no Bearer; a Circle seller proof signs
  the exact bytes sent and recovers to payTo; a 401 from `/settle` credits nothing (#5a–5c).
- **Celo's 400 verdicts** — x402-rs answers a rejected payment with HTTP 400 + a verdict; that is a
  402 with the reason, while a *positive* answer under an error status is never believed (#5a2).
- **Fail closed** — testnet rails need explicit consent; unknown tokens, non-6-decimal tokens and a
  seller-proof key that does not control payTo disable the rail with a reason (#4).
- **Zero new crypto dependencies** — `lib/secp256k1.js` (RFC 6979) reproduces eth_account byte for byte
  and the exact example signature in Circle's settle API reference.

## Quick start

```bash
npm install
npm test                 # 57 tests
npm run probe            # $0 live proof every rail is payable by a stranger (see below)
node server.example.js   # a paid GET /paid/hello on the rails in your env
```

Configure extra rails per network name in `X402_EXTRA_NETWORKS` (e.g. `celo,arc`):
`X402_<NAME>_ASSETS` (default `USDC`), `_PAY_TO`, `_FACILITATOR_URL`, `_FACILITATOR_API_KEY`,
`_SELLER_PROOF_KEY` (Circle keyless trial only), `_RPC_URL`, `_ALLOW_TESTNET_CREDIT=1`.
